ATHENA GLOW UP

این پوشه یک وب‌اپ نصب‌شدنی (PWA) است.

برای نصب روی اندروید:
1) فایل‌ها را روی یک سرویس میزبانی HTTPS قرار بده (مثلاً GitHub Pages).
2) آدرس سایت را در Chrome اندروید باز کن.
3) از منوی سه‌نقطه گزینه Install app یا Add to Home screen را بزن.

نکته: برای نصب PWA باید سایت روی HTTPS یا localhost اجرا شود؛ بازکردن مستقیم index.html معمولاً امکان نصب کامل را نمی‌دهد.
پیشرفت چک‌لیست‌ها در حافظه مرورگر همان دستگاه ذخیره می‌شود. با پاک‌کردن داده‌های مرورگر ممکن است پاک شود.
